Calculadora Web

Proyecto desarrollado para el Reto 2 del módulo de Despliegue de aplicaciones web y móviles.

La aplicación consiste en una calculadora con un estilo identico a los estilos utilizados en aplicaciones de calculadoras para 
dispositivos moviles.

Para desarrollar la aplicación se utilizo HTML, CSS y JavaScript.

Para desplegar la aplicación se utilizo Apache.
